# Kala Fine Art website

Source for kalafineart.com, the site for live wedding painter Wamika Bansal.

- Pages: `index.html`, `live-wedding-painting.html`, `guest-portraits.html`, `custom-orders.html`, `contact.html`
- Styles: `css/style.css`
- Photos and videos: `assets/`

To change text, edit the `.html` files directly, or edit `build.py` and run `python3 build.py` to regenerate every page. Any change pushed to `main` is published automatically by GitHub Pages.
